# أعمالي

تطبيق جوال (PWA) لإدارة الحضور والانصراف: قراءة البصمة من حاضر+ عبر اختصار الآيفون، رصيد السماح الشهري، خطة المعالجة، والإشعارات.

## المكونات

| الجزء | التقنية |
|---|---|
| الواجهة | React + TypeScript + Vite + Tailwind، تُنشر على GitHub Pages |
| البيانات | Supabase (PostgreSQL + Auth + pg_cron + pg_net) |
| الإشعارات | دالة `push` (Web Push بدون مكتبات) تعمل كل 5 دقائق وبعد كل بصمة |
| القواعد | `src/lib/rules.ts` و`src/lib/notify.ts` مشتركة بين الواجهة والدالة |

## القواعد

- السماح الشهري 6:59، أيام العمل الأحد–الخميس، الدوام 7 ساعات.
- الحضور قبل 8:00 ← الانصراف 3:00. بين 8:00 و9:00 ← الحضور + 7 ساعات. بعد 9:00 ← تأخير والانصراف 4:00.
- الاستهلاك اليومي = التأخير + الانصراف المبكر، ويُخصم منه الاستئذان الجزئي المعتمد.
- الاستئذان اليومي والإجازة والتكليف والدورة والعطلة لا تُحتسب.

## الإعداد

1. Supabase: شغّل `supabase/migrations/0001_init.sql`، وانشر الدالة `supabase/functions/push` مع إيقاف Verify JWT.
2. ضع رابط المشروع والمفتاح العام في `.env.production`.
3. GitHub ← Settings ← Pages ← Source: GitHub Actions.

## التطوير
